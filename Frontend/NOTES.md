# Выбор стейт-менеджера

Экраны, API и подсветка отчёта — в [README.md](README.md).

Для фронта выбран **Zustand**.

Причины:

- В задании два экрана и простой набор состояния: текущий экран, фильтр месяца, фильтры табеля, данные с API, модалка формы.
- Zustand даёт один store без обвязки Redux (actions, reducers, providers) и без схемы MobX State Tree.
- Серверное состояние здесь несложное: явные `loadTimesheet` / `loadReport` после смены фильтра и после сохранения. React Query был бы полезнее при кэше, ретраях и множестве независимых запросов; здесь это лишняя сложность.
- Ошибки валидации с API кладутся в тот же store (`formError`, `fieldErrors`) и сразу показываются в модалке, а не только в консоли.

Компонентная библиотека не используется: по заданию достаточно полей, таблиц, кнопок и модального окна.
