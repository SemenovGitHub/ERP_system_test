# ERP Frontend

Фронтенд-приложение для системы управления рабочим временем на HTML, CSS и JavaScript.

## 🚀 Структура проекта

```
ERP_Frontend/
├── index.html      # Основная HTML страница
├── styles.css      # CSS стили (минималистичные)
├── script.js       # JavaScript для работы с API
├── nginx.conf      # Конфигурация Nginx
├── Dockerfile      # Docker образ для фронтенда
└── README.md       # Эта документация
```

## 📋 Функциональность

### Основные возможности:
- **Просмотр сотрудников** с пагинацией
- **Просмотр проектов** с пагинацией  
- **Просмотр записей времени** по году/месяцу с пагинацией
- **Отчеты по проектам** за определенный период
- **Создание новых записей времени**

### API Endpoints:
- `GET /api/employees` - список сотрудников
- `GET /api/projects` - список проектов  
- `GET /api/time-entries` - записи времени
- `GET /api/reports/projects` - отчеты по проектам
- `POST /api/time-entries` - создание записи времени

## 🐳 Docker

Фронтенд упакован в Docker контейнер на базе nginx:alpine.

### Сборка и запуск:
```bash
# Сборка образа
docker build -t erp-frontend .

# Запуск контейнера
docker run -p 3000:80 erp-frontend
```

### Доступ:
- Фронтенд: http://localhost:3000
- API должен быть доступен на: http://localhost:8080

## 🔧 Особенности реализации

- **Чистый HTML/CSS/JS** без фреймворков
- **Минималистичный дизайн** - только необходимые элементы
- **Адаптивная верстка** для мобильных устройств
- **Обработка ошибок** и показ статусов загрузки
- **Пагинация** для всех списков
- **Валидация форм** на клиенте
