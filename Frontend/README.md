# Frontend

React 18 + Vite + Zustand. Два экрана: табель и отчёт. UI без компонентной библиотеки. Почему Zustand — `NOTES.md`.

## Запуск

Через compose (nginx на :3000, `/api/` проксируется в ERP). Локально:

```bash
cd Frontend
npm install
npm run dev
```

API должен быть на :8080. Dev-прокси — `vite.config.js`.

```
src/
  App.jsx              # Табель | Отчёт
  store.js             # месяц (по умолчанию 2026-03), данные, модалки
  api.js               # fetch, разбор { message, validationErrors }
  screens/             # TimesheetScreen, ReportScreen
  components/          # форма записи, ставки, модалка
```

`node_modules/` и `dist/` в git не входят.

## Экраны

**Табель** — фильтр месяц/сотрудник/проект, CRUD записи, ставки, закрыть/открыть месяц. Стоимость и ставка приходят с API (на бэке `RateResolver`). На клиенте: часы шагом 0.5; нет ставки на дату — нельзя сохранить.

**Отчёт** — строки проекта за месяц: часы, стоимость, бюджет, % освоения.

Цвет строки (классы в `styles.css`):

- `.over` — перерасход (`isOverBudget`, `cost > budget`)
- `.risk` — риск без перерасхода (`isRisk`: освоение > 80%)
- иначе без подсветки

Перерасход важнее риска: красный, не жёлтый.

Ставки: на дату записи действует последняя с «действует с» ≤ этой даты. После сохранения — `bootstrap()`, на экране отчёта ещё `loadReport()`.
